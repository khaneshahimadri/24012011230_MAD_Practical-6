# ⏰ MAD Practical-6 – Alarm Application

## 🎯 Aim
To develop an Android application to **set and manage alarms** using Kotlin.

## ✨ Features
- ⏰ Set Alarm
- 🕐 Select alarm time
- 🔔 Alarm ringtone
- 📳 Vibration support
- 🛑 Stop/Cancel alarm

## 🛠️ Technologies Used
- Kotlin
- XML
- Android Studio
- AlarmManager
- BroadcastReceiver
- MediaPlayer

## 📚 Concepts Learned
- AlarmManager
- BroadcastReceiver
- TimePicker
- Android Permissions
- Event Handling

## ⚠️ Challenges Faced
- Setting alarm at the selected time
- Handling alarm ringtone
- Managing vibration and alarm stop functionality
